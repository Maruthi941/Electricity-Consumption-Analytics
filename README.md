# Electricity Consumption Analytics

## Project Overview
Electricity Consumption Analytics is a Big Data Analytics project developed using Python, Pandas, PySpark and SQLite.

The project analyzes electricity consumption patterns and generates daily, hourly and monthly consumption summaries.

## Technologies Used
- Python
- Pandas
- NumPy
- PySpark
- SQLite
- Matplotlib
- Power BI

## Project Features
- Electricity dataset generation
- Data cleaning and preprocessing
- Big Data processing using PySpark
- Daily electricity consumption analysis
- Hourly electricity consumption analysis
- Monthly electricity consumption analysis
- Data visualization
- SQLite database storage

## Project Structure
```text
Electricity_connsumption_analytics/
├── data/

```

## How to Run

1. Install Python.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib pyspark
```

3. Run the project:

```bash
python main.py
```

## Output
The project generates:
- Daily consumption analysis
- Hourly consumption analysis
- Monthly consumption analysis
- Processed electricity datasets
- Visualization graphs
